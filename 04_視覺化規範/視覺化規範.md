# 每日日文新聞講義｜視覺化規範

模板：`04_視覺化規範/講義模板.html`（2026-11-25 版，內容是當天新聞的範例）。
每天複製模板、只替換內容，不改 CSS 和結構。

## 紙張與整體

- A4 直式，固定 2 頁，內容不可超出頁面（交件前截圖自己看一次）。
- 外框：灰藍色底 `#84A5B1`，內頁白色圓角，加淡色 5mm 方格紙紋路。
- 列印要保留背景色（`print-color-adjust: exact`）。

## 顏色

| 用途 | 色碼 |
|---|---|
| 主色（標題框、單字、標籤） | 深青色 `#004C5D` |
| 強調色（日期標籤、編號、例句標籤、重點數字） | 橘色 `#E8704A` |
| 螢光筆底線 | 淡橘色 `#FBD3C2` |
| 卡片邊框、導言色條 | `#B9D3DA` |
| 「對學生的影響」底色 | 淡粉色 `#FBEDEE` |
| 次要文字、出處 | 灰色 `#6B7B80` |

## 字體

- 中文：Microsoft JhengHei；日文：Yu Gothic（備用 Meiryo）。
- 日文段落一律加 `lang="ja"`。

## 第 1 頁（由上到下）

1. **Header**：左上小字「あき ・ 每日日文新聞」＋大標「今日的經濟新聞」（科技日改為「今日的科技新聞」）；右側橘色日期標籤「YYYY.MM.DD（星期）」；下方深青色分隔線。
2. **標題框**：深青底白字，新聞標題（日文，加假名）＋一行「NHKニュース ｜ 日期時間 ｜ 分類」。
3. **新聞導言（原文）**：左側淡藍色條；今日單字在原文中用粗體＋淡橘色螢光筆標出。
4. **① 這則新聞的三個重點**：三張獨立卡片，左側放大號橘色數字，關鍵字粗體。
5. **② 這則新聞對學生的影響**：標題旁註明「（以下是整理者的分析，不是新聞內容）」；淡粉底條列，每點用橘色粗體小標，結尾加「（推論）」。和股價有關一律寫「推論，非投資建議」。
6. **③ 今日 3 個單字**：標題旁註明「例句皆取自日本網路上的實際用例，非自創」；第 1 頁放第 1 個單字。
7. **頁尾**：新聞來源（標題＋網址＋日期）｜ p.1

## 第 2 頁

1. **Header**：同第 1 頁格式，大標為「今日的經濟新聞（續）」或「今日的科技新聞（續）」，字級較小。
2. 第 2、3 個單字卡。
3. **④ 重點文法**：卡片左邊框改橘色。
4. **頁尾**：例句連結 ｜ p.2

## 單字卡格式

- 標題列：單字（加假名，大字深青色）＋讀音（灰）＋詞性・JLPT 級數（外框標籤）＋中文意思（粗體）。
- 下方每列左側一個小色塊標籤：
  - `文中`（深青）：新聞原句，目標單字用螢光筆標出
  - `接續`（灰藍）：可接續的文法或詞彙＋中文
  - `例句`（橘）：真實例句（目標單字螢光筆標出）＋灰色中文翻譯
- 最下方小灰字出處：「— 網站名「文章標題」（日期）」。

## 文法卡格式

- 標題列：文法＋JLPT 級數＋中文意思。
- 列：`用法`（綠）、`接續`（灰藍）、`文中`（深青）、`例句`（橘），最後附出處。

## 假名

- 所有漢字都要用 `<ruby>` 標假名（標題、導言、單字、例句都要）。
- 注意特殊讀音，例如「9日」要整組標「ここのか」。

## 週六複習講義（複習模板.html）

沿用上面的顏色、字體、外框、Header 和頁尾，A4 固定 2 頁。

- **第 1 頁**：Header 大標「本週複習」，日期標籤寫本週範圍（例如「2026.11.23 – 11.28」）
  1. 摘要框：本週講義份數（標出哪天、經濟或科技）、單字數、文法數；缺哪幾天要寫出來
  2. **① 本週單字**：表格，欄位為「單字（加假名）｜讀音｜詞性・級數｜中文｜出處」，出處用小色塊標「經濟」（深青）或「科技」（綠 `#5C8A6E`）＋日期＋新聞主題
  3. **② 本週文法**：每個文法一張橘色左邊框卡片，標題列＋`接續` 一列
- **第 2 頁**：Header 大標「本週複習（小測驗）」
  1. **③ 單字填空** 5 題：真實例句挖空，空格用深青色底線
  2. **④ 文法選擇** 3 題：真實例句挖空＋Ⓐ Ⓑ Ⓒ 三個選項
  3. **⑤ 解答**：淡粉底框，列出答案和每題句子的出處
- 題目句子只能用本週講義裡已有的真實例句，不可自創。

## 輸出

- 平日檔名：`YYYY-MM-DD_每日日文新聞_<經濟 或 科技>_<主題關鍵字>.pdf`
- 週六檔名：`YYYY-MM-DD_每週複習.pdf`
- 都存進 `03_每日新聞PDF`。
- 用 Chrome 無頭模式轉 PDF 時要加 `--no-pdf-header-footer`，不然會印出瀏覽器的網址和日期。
