以下是雲端版的差異，和原指示衝突時以這份為準。日期與星期一律用 Asia/Taipei 時區判斷。

## 0. 先檢查要不要做

- 用 Drive 的 search_files 查資料夾（查詢：`parentId = '1HKkYPAbq_I9EGWM7xysa2lKHR1w0Cutc'`）。
- 若已經有今天日期開頭、且不含「雲端測試」的講義，代表今天做過了：不要重做，直接跳到第 7 步通知「今天已產出」。
- 週六、週日不產出平日講義（週六複習另有排程）。

## 1. 準備環境

- `npm ci`
- `apt-get update && apt-get install -y fonts-noto-cjk`（不是 root 就加 sudo），用 `fc-list :lang=ja` 確認有日文字體。
- 不要跑 `npx playwright install`：Chromium 已預裝在 /opt/pw-browsers，抓取腳本會自動找到並自動走 HTTPS_PROXY。
  自己寫的轉 PDF 程式也要用 executablePath 指向 /opt/pw-browsers/chromium-*/chrome-linux*/chrome（本地 file:// 頁面不需要 proxy）。

## 2. 讀 NHK

- 只用 `node scripts/nhk-fetch.mjs list <分類頁網址>`（印出「標題<TAB>網址」）挑新聞，
  `node scripts/nhk-fetch.mjs article <新聞網址>` 讀全文。
- 使用者已親自授權按 NHK ONE「海外からのアクセスについて」視窗的「確認して進む」，腳本只會按這一個按鈕。
- 腳本 exit 3（出現受信契約的用途／地域申報等其他視窗）：不要自己操作視窗、不要換新聞來源，停止並回報腳本輸出。
- 腳本其他錯誤（逾時等）最多重試 2 次，仍失敗就停止回報（附上 proxy 擋掉的網域），不要用其他方式繞過。

## 3. 避開本週已教過的內容

- 本週＝本週一到今天（Asia/Taipei）。從第 0 步的查詢結果找出本週的講義 PDF（檔名開頭是日期），
  用 download_file_content 下載，再用 `pdftotext` 讀出內容，列出已教過的單字和文法。
- 也看 repo 的 03_每日新聞PDF 裡本週的講義。
- 這些單字和文法都不可重複。讀不到某份講義時，在報告寫明是哪一份。

## 4. 找例句

- 優先用 NHK やさしいことばニュース：用 WebSearch 找 https://news.web.nhk/news/easy/<id>/<id>.html 的文章，
  再用 `node scripts/nhk-fetch.mjs article <網址>` 讀全文，確認句子逐字存在才可用。
  （news-list.json 需要登入 token，不要嘗試。）
- 每個單字和文法各用一句不同的例句，不可共用。
- 避開死傷事件、犯罪細節的句子。
- 找不到可確認的例句就換單字，絕不自創或猜。標出處（網站名、文章標題、日期）。

## 5. 轉 PDF

- 複製模板只替換內容。只能在 CSS font-family 後面補 "Noto Sans CJK TC","Noto Sans CJK JP" 作備用，
  其他 CSS（含顏色）和結構不改。
- 用 Playwright 的 page.pdf({format:'A4', printBackground:true})。
- 確認剛好 2 頁、內容沒超出頁面：轉成圖片自己看，超出就精簡文字重做。

## 6. 上傳 Drive

- 檔名：YYYY-MM-DD_每日日文新聞_<經濟 或 科技>_<主題關鍵字>.pdf
- Drive connector 的 create_file：parentId=1HKkYPAbq_I9EGWM7xysa2lKHR1w0Cutc，contentMimeType=application/pdf，
  disableConversionToGoogleType=true，base64Content 用 `sha256:<64 位小寫 hex>:<檔案絕對路徑>` 檔案參照。
- 不要 commit 或 push 任何東西到 git。

## 7. 通知（成功或失敗都要做，放在最後）

- 用 PushNotification 發一則簡短結果。
- 用 ntfy 發一則：
  `curl -sS -m 20 -H "Content-Type: text/plain; charset=utf-8" -H "Title: aki news" --data-binary "<訊息>" https://ntfy.sh/aki-news-9f3k2x`
  訊息只寫日期、成功或失敗、新聞標題和 Drive 連結（成功時）或卡在哪一步（失敗時）。
  這個主題是公開的，不要放其他個人資訊。若 ntfy.sh 被 proxy 擋（403），在報告寫明即可，不要繞過。
